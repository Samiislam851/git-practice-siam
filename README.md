**Author:** Samiul Islam Siam

## What This Project Does

A small Python project used to practice Git and GitHub workflows. It prints the
author's name and today's date, and provides a set of simple calculator functions.

## Project Structure

```
git-practice-siam/
├── README.md
├── .gitignore
├── src/
│   ├── main.py
│   └── utils.py
└── docs/
    └── project-description.md
```

## How to Run

```bash
python3 src/main.py
```

## Features

- Prints the author's name and the current date
- Calculator helpers: `add`, `subtract`
